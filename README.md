# 💰 MisFinanzas

App que hice para llevar el control de mis gastos personales 
y no perderme en las quincenas.

## ¿Qué hace?

- Ver cuánto gasto por semana
- Registrar gastos fijos como renta, luz, agua
- Guardar metas de ahorro
- Anotar gastos extras del día a día

## Hecha con

- Kotlin + Android Studio
- HTML, CSS y JavaScript adentro del WebView

## Requisitos

- Android 7.0 o superior
